# Les prompts des illustrations

Les illustrations sont des **paysages seuls** : aucun personnage, aucune créature, aucun vaisseau. Le jeu montre l’image du monde visité, sur toutes ses scènes et sur sa fiche du Guide. Chaque type de monde a plusieurs images, et le jeu évite de te redonner une image déjà vue tant qu’il en reste d’autres pour ce type.

Pour chaque image : colle le prompt maître dans ChatGPT, puis la description juste après « Scène : ». Envoie-moi l’image avec son nom (par exemple `rocheux-b`), je la convertis et je l’intègre.

Toutes les images sont à refaire en paysages seuls : les anciennes, avec un explorateur dedans, restent en place jusqu’à ce que leur nouvelle version arrive, puis je les remplace une à une. Les nouveaux mondes (bibliothèque, chantier, champignon, cimetière, plat, dessiné) entrent dans la galaxie avec leur première image.

Refaites en paysages seuls : 33 sur 54 (`rocheux`, `rocheux-b`, `rocheux-c`, `gazeux`, `gazeux-b`, `gazeux-c`, `desert`, `desert-b`, `desert-c`, `glace`, `glace-b`, `glace-c`, `volcan`, `volcan-b`, `volcan-c`, `toxique`, `toxique-b`, `toxique-c`, `crateres`, `crateres-b`, `crateres-c`, `ocean`, `ocean-b`, `ocean-c`, `jungle`, `jungle-b`, `jungle-c`, `tempere`, `tempere-b`, `tempere-c`, `etrange`, `etrange-b`, `etrange-c`).

## Le prompt maître

```
Illustration pour un jeu mobile d’exploration spatiale humoristique, dans le style de Moebius (Jean Giraud) : ligne claire, trait d’encre fin et régulier, grands aplats de couleur, peu d’ombres, paysages immenses et perspective ample. Palette pastel et chaude, comme une impression pulp des années 50 : papier crème, sépia, brique, vert-de-gris, lavande, orange doux, rose, bleu encre. Une légère trame de points dans les ciels et les ombres, et un léger décalage des couleurs, comme une impression mal calée. Ton : absurde et poétique, à la façon du Guide du voyageur galactique et du Disque-monde ; l’étrange est traité calmement, avec humour, jamais comme de l’horreur. Uniquement le paysage : aucun personnage, aucune créature, aucun animal, aucun vaisseau, aucun astronaute. Garder un espace dégagé et simple au centre de l’image, au niveau du sol, comme une scène vide. Aplats francs et contours nets, pas de rendu peint ni de dégradés, peu de détails : de grandes surfaces simples. Pas de planète géante ni de grosse lune dans le ciel, sauf si la scène le demande. Format portrait vertical 2:3. Aucun texte, aucune lettre, aucun chiffre, aucune signature, aucun logo, aucun cadre.

Scène :
```

## Les mondes

Les quatre premiers (rocheux, gazeux, désert, glace) font les deux tiers des tirages : c’est là que les images se voient le plus.

## Les objets de la soute

20 objets : 4 séries, 5 paliers. Une image par objet, **sur fond transparent**, nommée `<série>-<palier>` (par exemple `epaves-1`). Elle remplit la tuile de la soute, sur la couleur de sa série ; le palier reste écrit dans un coin. Plus le palier est haut, plus l’objet doit avoir l’air précieux, imposant ou étrange.

### Le prompt maître des objets

```
Objet pour l’inventaire d’un jeu mobile d’exploration spatiale humoristique, dans le style de Moebius (Jean Giraud) : ligne claire, contour d’encre bleu nuit épais et net, grands aplats de couleur, peu d’ombres, palette pastel et chaude d’impression pulp des années 50. Un seul objet, entier, centré, vu de trois quarts, qui remplit presque toute l’image, lisible même tout petit (comme une icône de 64 pixels). Fond transparent (PNG avec canal alpha), sans ombre portée, sans décor, sans cadre, sans personnage. Aucun texte, aucune lettre, aucun chiffre. Format carré.

Objet :
```
